# Gusta Dev Tech

Site de apresentação de **Gustavo Rodrigues | Dev & Design** (@gusta_dev_tech), Pesqueira, PE.
Sites, landing pages, agentes de IA, logos, design 3D e animações.
Gusta Dev Tech | Dev & Design
Portfólio profissional de Gustavo Rodrigues, desenvolvedor e designer em Pesqueira, Pernambuco. O site apresenta serviços digitais, projetos e canais de contato para novos clientes.
✨ Sobre o projeto
O site foi desenvolvido como uma página responsiva de apresentação profissional, com identidade visual escura e detalhes dourados. A proposta é mostrar os serviços de forma clara e facilitar o contato para solicitar orçamentos.
🛠️ Serviços apresentados
- Sites institucionais
- Landing pages
- Agentes de inteligência artificial
- Criação de logos
- Design 3D
- Animações
🚀 Recursos
- Layout adaptável para celular e computador
- Seções de serviços, portfólio, apresentação e perguntas frequentes
- Formulário de orçamento que prepara uma mensagem para envio pelo WhatsApp
- Links para contato pelo WhatsApp e Instagram
- Animações e efeitos visuais
- Metadados básicos para mecanismos de busca e compartilhamento em redes sociais
- HTML, CSS e JavaScript no mesmo arquivo
💻 Tecnologias
- HTML5
- CSS3
- JavaScript
- Google Fonts: Bricolage Grotesque e Figtree
▶️ Como executar localmente
1. Baixe ou clone este projeto.
2. Abra o arquivo index.html em um navegador.
O site é estático e não exige instalação de dependências ou processo de build para a visualização básica.
🌐 Publicação
Por ser um site estático, ele pode ser publicado em serviços de hospedagem compatíveis, como Cloudflare Pages ou Vercel. Para usar um domínio próprio, configure os registros DNS do domínio conforme as instruções do provedor escolhido.
